


명령어 집합 구조 : CPU가 이해할 수 있는 명령어 모음
	=> CPU는 명령어 집합에 있는 명령어만 이해할 수 있다.
	
	- ISA : 하드웨어가 소프트웨어를 어떻게 이해할지에 대한 약속

	- CISC (Complex Instruction Set Computer) 
		- 복잡한 명령어 집합을 활용하는 컴퓨터
		- x86 - 64 기반 명령어 집합 구조
		- 크기가 다양한 가변 길이 명령어를 활용
		- 적은 수의 명령어들로 컴퓨터를 실행할 수 있다.

		- 단점 
			- 명령어 파이프라인이 불리
			- 명령어 크기와 실행되기까지의 시간이 다름
				=> 가변적 길이로 시간이 다르니까 여러 클럭이 필요한 경우가 있음 

	- RISC (Reduced Instruction Set Computer)
		- 명령어 종류가 적다
		- 크기가 일정 
		- 짧게 규격화된 명령어 사용
		- 명령어 파이프라인이 유리
		- 메모리 접근 최소화(Load, Store)
		- 1클럭 내외 명령어 수행
