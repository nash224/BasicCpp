{
	- 텍스트 형식의 쉼표 구분

	- (Custom) 쉼표로 구분된 필드 사이에 공백이 있거나 없을 수도 있음

	== 행 ==
	{
		- 데이터 레코드
		- 둘 이상의 필드
	}

	== 구현 방식 ==
	{
		- std::string 객체에 저장

			--> 반복에서는 라인의 각 필드를 추출하고 std::vector에 저장하는 또 다른 루프를 넣음
	}
