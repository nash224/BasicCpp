
== SSO(Short String Optimaztion) == 
std:string 최적화 기법
스트링의 내부 배열에 24바이트보다 작으면 정적배열에 삽입해서 사용한다.
내부 변수는 Arr*, size_t, SSOArr이 있는데 기본 40바이트 할당에 Arr*와 size_t의 바이트 크기를 빼면 24바이트가 나옴
SSOArr << 임시 버퍼

== ObjectPool == 
미리 오브젝트를 할당해서 필요할때마다 가져오고 빼서 사용하는 오브젝트 기법
장점 : Delete와 New 연산 비용을 줄여주고 메모리 단편화를 줄인다.
단점 : 많은 오브젝트를 미리할당하기 때문에 프레임이 오히려 떨어질 수 있다.

== try catch ==
- MsgBoxAssert로 전부 throw 호출했기 때문에 쓸일이 거의 없었다.

- try 이 함수를 실행해보겠다.
- throw 예외가 생기면 변수를 던지겠다.
- catch 밖에서 예외를 받아 처리한다.

- 만약에 try로 시도하지 않으면 처리되지 않은 예외를 호출

- noexcept : 바깥으로 예외를 넘기지 않는다. << 바로 터트려버림
