== 뮤텍스 & 세마포어
뮤텍스와 세마포어라는 이론을 

- 뮤텍스 : 
--> Window에서 객체와 함수로 '크리티컬섹션' 이라고 표현함
	std에서는 #include <mutex> 뮤텍스라고 표현함
	- 유저영역
	- 특정 프로세스에서 관리하는 동기화 방식

- 세마포어 : 
--> Window에서 객체와 함수로 '세마포어' 이라고 표현함
	std에서는 #include <semapoa> 라고 표현함
	- 커널영역
	- 모든 프로세스를 관리하는 메모리에 영역으로 존재하고 있어. 번호를 메길수 있음
	- 모든 프로세스를 고려한 동기화 방식

- 약한 연결 
	- 서로 연관은 없지만 도움은 받는 연결방식
	- 메인 프로세스가 꺼져도 다른 권한을 가지고 있어 실행할 수 있음
	
- 강한 연결
	- 같은 권한을 가지고 있어 권한을 준 프로세스가 종류하면 내가 실행하고 있는 프로세스도 꺼져버림

멀티 프로세스
- 다른 메모리에 일을 맡길 수 있음
- 내 프로세스와 연관을 가질 수는 없지만, 데이터 송신이나 권한을 공유할 수 있음
- 장점 : 전혀 독립적인 메모리를 가지고 있기 때문에 일을 완전히 다르게 맡길 수 있음
	ex) Build, Loading 

멀티 쓰레드
- 내 프로세스의 메모리를 공유받고 있다.
- 스택을 여러개 만들어서 실행흐름을 가진다.
- DeadLock
