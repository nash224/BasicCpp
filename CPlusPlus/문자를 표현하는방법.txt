	
	
	
	문자 집합과 인코딩
		- 문자 집합(Character set)
			- 컴픁터가 이해할 수 있는 문자 모음

		- 인코딩 (encoding)
			- 코드화하는 과정
			- 문자를 0과 1로 이루어진 문자 코드로 변환하는 과정
			=> 문자 --> 데이터화

		- 디코딩 (decoding)
			- 코드를 해석하는 과정
			- 0과 1로 표현된 문자 코드로 변환하는 과정
				=> 데이터 --> 문자

		- ASCII 코드
			- 초창기 문자 집합
			- 알파벳, 아라비아 숫자, 특수 문자 및 제어 문자{Enter, ESC}
			- 7비트로 하나의 문자를 표현
			- 1비트는 오류 확인을 위한 패리티 비트(parity bit)
			- 코드 포인트 == 문자에 부여된 값

		- 한글 인코딩 
			- 알파벳은 이어서 쓰기 가능
			- 한글은 초성, 중성, 종성으로 조합
			- 완전형 인코딩 방식
				- 단어 하나하나에 숫자를 부여하는 방식

			- 조합형 인코딩 방식
				- 문자를 모두 더해 부여하는 방식

			- EUC-KR
				- 완성형 인코딩
				- 글자 하나에 2바이트 
				- 하지만 한글 모든 문자를 표현할 수 없음 { 꿹, 뙠 } 

		
	
	- UTF-8 , 유니코드 
		-모든 언어, 특수문자까지 통일된 문자 집합
		- 유니코드 인코딩 방식 : UTF-8, -16
		- 유니코드가 해석하는 방식은 16진수로 이루어진 코드를 다양한 방식을 통해 해석하는 것이다.

		- UTF-8
			- 유니코드 인코딩 방법
			- 가변 길이 인코딩 : 인코딩 결과가 1 ~ 4 바이트
				=> 유니코드에 부여된 [코드 포인트] 값에 따라 다름
				ex) 0000~007F, 0080~07FF
